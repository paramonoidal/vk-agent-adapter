# Пользовательские сценарии

## Обновление до OpenClaw 2026.8.1

Действие: установить `@openclaw-vk/vk@2026.8.31`, перезапустить gateway и выполнить `openclaw channels status --probe`.

Результат: VK-плагин загружается без ошибок SDK, канал работает в режиме Long Poll, probe возвращает `works`.

## Личное сообщение и ответ

Действие: разрешённый пользователь отправляет боту личное сообщение, агент отвечает текстом.

Результат: входящее сообщение попадает правильному агенту, ответ доставляется в тот же VK-диалог.

## Pairing нового пользователя

Действие: новый пользователь пишет боту при `dmPolicy: "pairing"`, затем оператор подтверждает полученный код.

Результат: доступ открывается только подтверждённому пользователю и только для исходного `accountId`.

## Несколько VK-сообществ

Действие: запросить и подтвердить pairing отдельно в двух именованных VK-аккаунтах.

Результат: подтверждение в одном сообществе не открывает доступ во втором.

## Входящие вложения

Действие: отправить одним сообщением изображение и документ.

Результат: агент получает оба вложения в исходном порядке с корректными типами и локально материализованными файлами.
